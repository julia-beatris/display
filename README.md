# 📚 Estudo de CSS Display

Projeto criado para estudar a propriedade `display` do CSS e entender, na prática, seus principais valores e casos de uso.

## 🎯 Objetivo

Explorar como diferentes valores de `display` alteram o comportamento, o posicionamento e a organização dos elementos HTML na página.

A ideia é aprender CSS através de exemplos práticos, comparando os diferentes tipos de display e observando seus efeitos no layout.

## 📌 Displays estudados

- `display: block`
- `display: inline`
- `display: inline-block`
- `display: flex`
- `display: grid`
- `display: none`

## 🧠 O que estou praticando

Durante o projeto, são explorados conceitos como:

- Comportamento de elementos em bloco e em linha;
- Espaçamento e dimensões dos elementos;
- Alinhamento e distribuição com **Flexbox**;
- Organização de layouts com **CSS Grid**;
- Ocultação de elementos com `display: none`;
- Diferenças entre os principais valores da propriedade `display`;
- Casos de uso práticos para cada tipo de display.

## 🛠️ Tecnologias

- HTML5
- CSS3

## 📖 Sobre o projeto

Este é um projeto de estudo desenvolvido para compreender melhor o funcionamento da propriedade display e sua importância na construção de layouts com CSS.

A proposta é aprender na prática, utilizando exemplos simples e visuais para entender quando e por que utilizar cada tipo de display
